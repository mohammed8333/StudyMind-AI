# StudyMind AI 🧠📚
### محرك المذاكرة والتعلم الذكي للطلاب العرب (Arabic-First AI Study Engine)

منصة تعليمية متطورة مصممة خصيصاً للطلاب في العالم العربي (مناهج الثانوية العامة والجامعات). بدلاً من الشات العام، يحول **StudyMind AI** أي كتاب مدرسي أو ملزمة أو مذكرة (PDF) إلى مدرس خصوصي تفاعلي، ومولد امتحانات ذكي، ومحلل تكيفي لنقاط الضعف.

---

## 🌟 أهم المميزات المبتكرة

1. **توثيق الإجابة برقم الصفحة والمصدر (Page Citations & Proofs)**:
   * عند الإجابة على أي استفسار، يُشير المعلم الذكي إلى رقم الصفحة المحدد داخل كتاب الطالب، مثل: `[المصدر: ص 37]`.
   * نقرة واحدة على رقم الصفحة تنقل عارض المستند فوراً إلى الصفحة المعنية.
2. **المعلم الذكي متعدد مستويات التبسيط (Tiered AI Tutor)**:
   * **بسيط جداً (تقنية فاينمان)**: تبسيط شديد وتشبيهات من الحياة اليومية لكسر رهبة المفاهيم الصعبة.
   * **متوسط**: شرح متزن وتدريجي خطوة بخطوة.
   * **مستوى الكتاب والمدرسة**: التزام حرفي بنص التعريفات والقوانين الواردة في المنهج لورقة الامتحان.
   * **متقدم وعميق**: براهين واستنتاجات وتطبيقات خاصة للمتفوقين.
3. **محرك التعلم التكيفي (Adaptive Learning & Mastery Diagnostics)**:
   * تشخيص دقيق على مستوى **المفاهيم (Concepts)** بدلاً من الاكتفاء بنسبة مئوية عامة.
   * تحديد فوري لنقاط الضعف (Weak Concepts) واقتراح خطة مراجعة ذكية واختبارات علاجية مركزة.
4. **محرك توليد الاختبارات والتصحيح الفوري (Quiz & Exam Engine)**:
   * توليد أسئلة (اختيار من متعدد MCQ، صح/خطأ) مرتبطة بمفاهيم محددة.
   * تصحيح فوري وتبرير تفصيلي لكل خيار استناداً لنصوص المنهج.
5. **معالجة مخصصة للنصوص العربية (Arabic NLP Pipeline)**:
   * حل مشكلات انعكاس وتفكك الحروف العربية في ملفات الـ PDF.
   * تنظيف وتطبيع النصوص (حذف التشكيل والتطويل وتوحيد الهمزات لغرض الفهرسة).
   * تقطيع هيكلي ذكي (Semantic Chunking) يحافظ على الأبواب والفصول والدروس وأرقام الصفحات.

## 🏗️ الهيكلية المعمارية (Tech Stack)

* **الواجهة الأمامية (Frontend)**:
  * Next.js 14 (App Router) + TypeScript
  * Tailwind CSS + خط Cairo العربي (دعم كامل للـ RTL)
  * Lucide React Icons
* **الباك إند (Backend)**:
  * FastAPI (Python 3.12) Async Architecture
  * SQLAlchemy 2.0 (Async) + Alembic
  * Pydantic v2 للتحقق الصارم من هياكل البيانات
  * PyMuPDF (`fitz`) لاستخراج صفحات ونصوص الـ PDF
  * `arabic-reshaper` + `python-bidi` لمعالجة اللغة العربية
* **قاعدة البيانات والبحث المتجهي (Vector DB)**:
  * PostgreSQL 16 مع إضافة `pgvector` عبر Docker Compose
  * دعم مرن للـ SQLite Fallback في بيئات التطوير السريع
  * بحث هجين (Hybrid Search): دمج البحث الدلالي المتجهي (Vector Cosine Similarity) مع البحث اللفظي المعياري (Lexical Arabic Search)
* **محرك الذكاء الاصطناعي (AI Engines)**:
  * محول مرن يدعم **Google Gemini API** (Gemini 2.0 Flash / Pro) لقوة الاستيعاب العربي والرؤية المدمجة
  * دعم كامل لتشغيل النماذج المحلية عبر **Ollama** (مثل `qwen2.5:7b` أو `llama3`)

## 🚀 البدء السريع (Quickstart)

### 1. تشغيل قاعدة البيانات (PostgreSQL + pgvector)
```bash
docker compose up -d
```

### 2. إعداد وتشغيل الباك إند (Backend)
```bash
# الانتقال لمجلد الباك إند وتفعيل البيئة الافتراضية
cd backend
venv\Scripts\activate  # أو source venv/bin/activate على Linux/Mac

# تشغيل السيرفر
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
* رابط التوثيق التفاعلي للـ API (Swagger UI): `http://localhost:8000/docs`

### 3. تشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend
npm run dev
```
* افتح المتصفح على: `http://localhost:3000`
